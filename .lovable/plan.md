# แผนสร้างภาพสรุปหลังวิเคราะห์

## สิ่งที่จะทำ
- ปรับภาพสรุปผลหลังนำเข้า Screenshot และกดวิเคราะห์ ให้มีหน้าตาใกล้ภาพอ้างอิงในธีม AURIQ navy–gold
- จัดข่าวเป็นกลุ่มตามวัน พร้อมเวลา ชื่อข่าว Forecast/Previous และระดับผลกระทบ
- แสดงทิศทางผลต่อทองอย่างชัดเจนด้วยลูกศรขึ้นสีเขียว, ลูกศรลงสีแดง หรือเครื่องหมายกลางสีทอง พร้อมคำว่า “บวกทอง / ลบทอง / เป็นกลาง”
- เพิ่มภาพรวมรายวันและบทสรุปทั้งสัปดาห์ โดยใช้ผลวิเคราะห์ที่มีอยู่และไม่สร้างตัวเลขที่อ่านจากภาพไม่ได้
- รักษาปุ่มดาวน์โหลด PNG เพื่อบันทึกภาพสรุปไปแชร์ได้

## การตรวจสอบ
- ทดสอบลำดับ วางภาพ → ตรวจข้อมูล → วิเคราะห์ → เห็นภาพสรุป
- ตรวจการจัดวางบนหน้าจอใหญ่และมือถือ รวมถึงข้อความไม่ล้นหรือถูกบัง
- ตรวจผลการสร้างโปรเจกต์และข้อผิดพลาดหน้าเว็บ

## รายละเอียดทางเทคนิค
- ใช้ข้อมูลที่ผู้ใช้ยืนยันจาก Screenshot และผลวิเคราะห์เดิม ไม่เพิ่มแหล่งข้อมูลจำลอง
- การแสดงลูกศรจะอ่านสถานะ Bullish/Bearish/Neutral จากผลวิเคราะห์ และมีสถานะกลางเมื่อระบุทิศทางไม่ได้
