# ใช้โลโก้ AURIQ และยึด UI ตามเอกสารแนบ

## สิ่งที่จะปรับ
- นำโลโก้ `auriq-logo-transparent.png` มาใช้เป็นโลโก้หลักในแถบด้านบนและพื้นที่แบรนด์ที่แสดงอยู่ โดยคงสัดส่วนและพื้นโปร่งใส
- สร้าง favicon จากโลโก้เดียวกันให้เหมาะกับขนาดเล็ก และนำ favicon เดิมออก
- คง UI แนวใหม่ตามไฟล์แนบ: dark navy/black, gold + cyan, liquid-glass panels, Dashboard สามคอลัมน์ และ News/Calendar ตาม visual baseline
- ไม่ดึง Portfolio, Journal, IBKR execution หรือหน้าตา legacy กลับมาใน AURIQ V1
- ไม่เปลี่ยนกฎสัญญาณ แหล่งข้อมูล หรือสถานะข้อมูลจริง/ตัวอย่าง

## การตรวจสอบ
- ตรวจ Dashboard ที่ 1672×941 และ 390×844
- ตรวจโลโก้ไม่บิด ไม่ล้น และอ่านได้ในแถบด้านบน
- ตรวจข้อผิดพลาดของหน้าและสถานะ build ล่าสุด

## รายละเอียดทางเทคนิค
- เก็บภาพหลักผ่าน Lovable Assets และอ้างอิงผ่านไฟล์ pointer
- ใช้ไฟล์ raster ขนาด 64×64 ใน `public/` สำหรับ favicon ตามข้อกำหนดเบราว์เซอร์
