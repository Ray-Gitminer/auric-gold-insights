# ปรับ AURIQ ให้ตรงภาพอ้างอิงและเพิ่มหน้าสัญญาณ

## ผลลัพธ์
- ปรับระบบสีทุกหน้าเป็น navy ดำไล่น้ำหนัก พร้อมขอบ cyan/gold และเงาแบบภาพอ้างอิง โดยคงโครงและข้อมูลเดิม
- ปรับ Dashboard ให้ใกล้ต้นฉบับขึ้นทั้งแถบเมนู โลโก้ ชื่อหน้า ระยะห่าง และสัดส่วน โดยไม่เปลี่ยนค่าข้อมูล
- เพิ่มหน้า **Signals** ที่รวมสัญญาณจากข้อมูลเศรษฐกิจทางการ กราฟแนวโน้มเศรษฐกิจ และกราฟ XAUUSD
- เตรียมการแสดง MT5 จริงให้ครบถ้วน โดยไม่แอบใช้ข้อมูลตัวอย่างเป็นข้อมูลจริง

## การดำเนินงาน
1. **Visual system ทุกหน้า**
   - ปรับสีพื้นและการไล่ระดับให้มีมิติใกล้ภาพ: navy/black, cyan edge glow, gold emphasis, red/orange/yellow ตามระดับผลกระทบ
   - ปรับการ์ดมาตรฐานให้เป็นกระจกเข้ม โปร่งเล็กน้อย ขอบสองชั้นและเงาด้านใน เพื่อให้หน้าเดิมทั้งหมดได้รูปแบบเดียวกัน

2. **Dashboard**
   - ปรับเมนูบนให้มี Dashboard, Signals, News, AURIQ Flow, Strategy และปุ่ม Live Calendar ตามภาพ โดยลิงก์เฉพาะหน้าที่มีจริง
   - ใช้โลโก้ที่ผู้ใช้อัปโหลดแล้ว ปรับขนาดและตำแหน่งให้ตรงต้นฉบับ
   - ปรับชื่อหน้า สี ขนาดตัวอักษร ความแน่นของกราฟ และสัดส่วนการ์ด โดยไม่แก้แหล่งข้อมูลหรือค่าที่แสดง

3. **Signals ใหม่**
   - สร้าง `/signals` เป็นพื้นที่สามคอลัมน์แบบเดียวกับ Dashboard
   - ใช้ข้อมูล Economic Calendar จาก BLS/BEA/FRED/Census ที่มีอยู่จริง พร้อม Actual/Consensus/Previous และ TrendChart จาก historical series
   - ใช้ deterministic signal engine กับ candles จริงจาก MT5 เท่านั้น; หาก MT5 ยังไม่เชื่อม จะแสดงสถานะรอเชื่อม ไม่สร้างสัญญาณซื้อขายจาก fixture
   - แสดงกราฟทองผ่าน GoldChart และป้ายแหล่งข้อมูลอย่างชัดเจน

4. **MT5**
   - คง data contract ปัจจุบัน: MT5 Connector Agent บน Windows อ่าน XAUUSD แล้วส่งเข้า `mt5_candles`
   - Dashboard เปลี่ยนเป็น MT5 LIVE เฉพาะกราฟเมื่อมีบัญชี connected และมี candles จริงเท่านั้น
   - เนื่องจากตอนนี้ยังไม่มี Agent ทำงาน จะไม่รายงานว่าเชื่อมสำเร็จ; UI จะบอกว่ารอ Connector Agent
   - รองรับโบรกเกอร์ส่วนใหญ่ที่ใช้ MT5 Desktop และอนุญาต EA; ต้องเปิด MT5+Agent หรือรันบน Windows VPS

5. **ตรวจสอบ**
   - ตรวจ TypeScript และ build log
   - ตรวจภาพจริงที่ desktop 1672×941 และ mobile 390×844
   - แก้ข้อความล้น แนวนอนล้น กราฟถูกบัง และรักษาองค์ประกอบ desktop ตามภาพ
